About This Site

A free collection of 108 browser games, built with plain HTML, CSS, and JavaScript.

HTML5 Games is a free browser-games collection built for quick, casual play. Instead of sending you to downloads or app stores, every title here runs instantly on the page — a design that works well for students on a break, office users with five spare minutes, and families looking for simple games on a shared tablet.

The collection focuses on proven, easy-to-understand formats: the classic Snake formula, the number-merging puzzle 2048, the concentration game Memory Match, the paddle-and-bricks challenge of Breakout, the one-tap timing of Flappy Jump, the deduction of Minesweeper, and the evergreen Tic Tac Toe. Each game includes its own controls explanation in the player, a visible score, and a restart option so you can immediately try to beat your last result.

Every game here is written by hand in plain HTML, CSS and JavaScript — no game engine, no copied code packs, and no embedded third-party players. That keeps each game small (the whole page loads in about a second on a typical connection), makes the controls identical on every device, and means a game you learn today plays exactly the same next month. The written guides on this page are original to this site and are updated whenever a game's rules or controls change.

HTML5 Games is family-friendly: there is no chat, no account system, no gambling or cash prizes, and nothing to buy inside any game. Scores exist purely for your own satisfaction. If you are a teacher or parent, the puzzle and memory games are a safe pick for short brain breaks — they need no personal information from the player at all.

New categories and games can be added over time while keeping the same promise: fast loading, clear controls, and honest, playable games — not screenshots or links to elsewhere.

Game Details, Accessibility & Support

Supported browsers & devices

All 108 games run in current versions of Chrome, Edge, Firefox and Safari on Windows, Mac, Linux, Android and iOS. They are built with HTML5 Canvas and standard JavaScript — no plugins, no downloads, no accounts. If a game does not start, updating your browser almost always fixes it.

Accessibility

Snake and 2048 are fully playable by keyboard alone (arrow keys or WASD), and every game can be operated with a mouse or touch. On-screen direction buttons are provided for Snake and 2048 on touch devices. Scores and status messages are shown as text on the game screen. The games currently have no sound, so they can be played in quiet places without missing anything.

Scores & saving

Scores exist only on the game screen while you play. Nothing is stored — this page does not save scores, use accounts, or keep a leaderboard, and closing the tab clears the current game. Minesweeper guarantees your first click is always safe; Memory Match shuffles its eight pairs fresh every game.

Known limitations & updates

Version 2.0, updated November 2026: 108 playable games across eight categories — Arcade, Puzzle, Brain, Classic, Action, Racing, Sports and Word — including the original seven (Snake, 2048, Memory Match, Breakout, Flappy Jump, Tic Tac Toe and Minesweeper), each with controls explained in the player. Known limitations: only one game runs in the player at a time; switching games ends the current run; Breakout is easiest with a mouse or touch drag. Found a bug? Report it through the Contact section with the game name, your device and your browser, and it will be checked for the next update.
