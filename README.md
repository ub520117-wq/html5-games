# HTML5 Games

Free HTML5 browser games — 108 playable games, no download, no sign-up.

Live site: https://html5-games-six.vercel.app/

## Structure (multi-page static site)

- `index.html` — homepage: hero, game player, full game grid with search/filter, category/guide/article links
- `assets/style.css` — shared stylesheet (bright light theme)
- `assets/games.js` — shared game engine: 108 games (7 bespoke + engine-based)
- `games/<id>.html` — one playable page per game (108), each with description, how-to-play, tips, and related games
- `guides/<slug>.html` — 8 game guides (+ `guides.html` index)
- `articles/<slug>.html` — 6 strategy articles (+ `articles.html` index)
- `categories/<cat>.html` — 8 category pages (+ `categories.html` index)
- `about.html`, `contact.html`, `privacy.html`, `terms.html`, `dmca.html`, `faq.html`, `how-to-play.html`
- `sitemap.xml`, `robots.txt`

## Build

Generated by `~/workspace/html5-games-build/build.py` from the single-file
108-game version. Re-run the script to regenerate the whole site.
